# Public assets

`findmate-social-preview.png` is the repository's 1280×640 social preview.
It is intentionally free of owner data, agent identities, external logos, and
tracking. The same image appears in the project README so the value proposition
stays consistent before and after a click.

The image was generated for FindMate with OpenAI image generation, then resized
losslessly to GitHub's recommended dimensions. The source prompt requested a
dark, high-contrast card showing two complementary abstract owner profiles
connected through an AI-agent layer, with the exact public copy visible in the
image.
